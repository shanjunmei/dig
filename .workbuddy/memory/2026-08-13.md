# 2026-08-13

## GitHub Pages 增加中英文切换
- `docs/index.html` 在每个可翻译元素上加 `data-en`（纯文本）或 `data-en-html`（含 `<code>`/`<strong>` 等标签）属性，原文（中文）作为默认，代码块保持不变。
- `docs/assets/js/main.js` 增加 i18n 逻辑：捕获原始中文 → `localStorage`(key `dig-lang`, 默认 `zh`) 持久化 → 切换 textContent/innerHTML，并同步 `<title>` 与 meta description、按钮高亮。
- `docs/assets/css/style.css` 增加 `.lang-switch` 分段控件样式（桌面/移动端均显示）。
- 导航栏右上加入「中文 / EN」切换按钮。
- 注意坑：`data-en-html` 内若需显示字面 `<pkg>`，属性里要写成 `&amp;lt;pkg&amp;gt;`（双重转义），否则 `innerHTML` 会把它当成真实标签吞掉。
- 部署方式同前：仓库 Settings → Pages → Deploy from a branch → main → /docs。本地预览 `python -m http.server` 于 docs/ 目录。

## 代码窗口注释也做成双语
- 之前 `named_instances.go`（4 处纯中文注释）与「生成并运行」终端（`# or go generate ./...` 纯英文）是单语。
- 修复：给这 5 处 `<span class="c-comment">` 加 `data-en`；其中英文那条把默认文本翻成中文 `# 或 go generate ./...`、英文走 `data-en`，与 i18n 方向一致。
- 3 处中性 Go 指令（`//go:build digen` ×2、`//go:generate …`）保留不翻译（非散文注释）。
- 验证：5 处均在 `[data-en]`，HTML 解析无异常。
