## 发现并修复的 Bug

### 1. `example/db/db.go` — RedisClient.Ping 参数遮蔽
- `Ping(index RedisDbIndex)` 内部 Printf 使用了包级变量 `Index` 而非参数 `index`
- 修复：改为 `index` 参数

### 2. `internal/extractor/extractor.go` — Supply 重复绑定错误消息
- 两个默认（未命名）Supply 提供相同类型时，错误消息显示 `with name ""` 而非 `(default)`
- 根因：`keyNamed == keyDefault` 时（都是 `retType`），`keyNamed` 检查先匹配
- 修复：重构为 `if instanceName != "" { ... } else { ... }` 分支
