# 2026-08-12 — 创建 GitHub Pages 站点

## 工作概要
为 dig 项目创建了 GitHub Pages 静态站点，放置在 `docs/` 目录。

## 文件结构
- `docs/index.html` — 主页面（Hero、Why dig、核心特性、快速开始、API、对比矩阵、示例、版本亮点）
- `docs/assets/css/style.css` — 样式（Go cyan 主题、响应式、代码高亮）
- `docs/assets/js/main.js` — 交互（导航栏滚动、移动端菜单、对比矩阵 Tab 切换、平滑滚动）

## 设计要点
- Go 风格配色（#00ADD8 cyan），响应式布局，macOS 风格代码窗口
- 语法高亮使用手写 CSS span 标签（无外部 JS 依赖）
- 对比矩阵使用 5 个 Tab 切换（架构/API/错误处理/运行时/项目状态）
- 版本亮点使用时间线展示
- 零外部依赖（无 CDN、无框架、无构建工具）

## 部署方式
GitHub 仓库 Settings → Pages → Source: `main` branch, `/docs` folder
